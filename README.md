# Consola landing page v1

## Project structure

- `index.html`
- `css/styles.css`
- `js/main.js`
- `assets/`

Copy your existing files into `assets/`:
- `consola-logo.png`
- `example-homepage.png`

## Screenshot files to add later

The v1 intentionally uses visual placeholders for product screens that should be retaken cleanly.

Recommended filenames:
- `access-governance.png`
- `excel-upload.png`
- `capacity-management.png`
- `module-configuration.png`

Once you have those screenshots, replace the placeholder blocks in `index.html` with `<img>` elements.

## Important pre-launch checks

1. Verify the final security/data-residency wording with the development agency.
2. Confirm whether the Azure Portal Marketplace URL should be replaced with a public Marketplace listing URL.
3. Confirm all pricing limits before publishing.
4. Add real customer logos only after explicit permission.
5. Add privacy/legal links if required before launch.
