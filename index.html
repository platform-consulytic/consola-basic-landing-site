FAQ

Veelgestelde vragen

Heeft iedere externe gebruiker een Power BI Pro-licentie nodig?

Nee. Met Power BI Embedded kunnen externe gebruikers rapportages bekijken zonder eigen Power BI-licentie. Consola kan ook gebruikers ondersteunen die zich met hun eigen account bij Power BI aanmelden.

Vervangt Consola Power BI of Microsoft Fabric?

Nee. Power BI levert nog steeds de rapportages en Fabric levert nog steeds de gegevenshulpmiddelen. Consola biedt gebruikers één portaal en beheerders één plek om alles te beheren.

Waar wordt Consola geïmplementeerd?

Consola wordt via Azure Marketplace in je Azure-omgeving geïmplementeerd.

Kunnen we onze bestaande Power BI-rapportages gebruiken?

Ja. Consola maakt verbinding met je Power BI- en Fabric-workspaces. Je kiest welke rapportages in elke module verschijnen.

Kan Consola Row-Level Security afdwingen?

Ja. Consola kan de juiste Row-Level Security-gegevens naar Power BI sturen. Een gebruiker kan een rapportage openen, maar ziet alleen de gegevens waarvoor die persoon rechten heeft.

Hoe werken updates?

Consulytic kan updates voor Consola via Azure uitvoeren. Tijdens een update kan Consola tijdelijk minder of niet beschikbaar zijn. Updates worden vooraf aangekondigd.
